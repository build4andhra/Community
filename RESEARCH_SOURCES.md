# Research Sources

Sources to support ongoing review of community governance and legal obligations. This is not an exhaustive legal survey. Verify current versions and applicability before relying on any source.

- GitHub Open Source Guide — Legal: https://github.com/github/opensource.guide/blob/main/_articles/legal.md
- GitHub community management and moderation: https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/about-community-management-and-moderation

- Choose a License: https://choosealicense.com/
